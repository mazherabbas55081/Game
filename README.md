# REAL DRIVE - Pakistan 🌐🏎️

Browser-ready version of the REAL DRIVE Python/Pygame game.

## Build for Web

Install the tools:

```bash
pip install -r requirements.txt
```

Then build:

```bash
pygbag main.py
```

The generated web build can be uploaded to a static web host that supports HTML5/WebAssembly game files, such as itch.io.

## Controls

- W / Up Arrow = Accelerate
- S / Down Arrow = Brake
- A / Left Arrow = Move Left
- D / Right Arrow = Move Right
- SPACE = Nitro
- ESC = Pause
- ENTER = Play Again

## Important

This is a browser-compatible Pygame build. Some browser/mobile environments may require touch controls to be added separately.
